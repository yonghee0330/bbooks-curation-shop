사람들은 동물이 사람처럼 말할 수 없고, 사람처럼 생각할 수 없으며, 자신에 대해 생각할 수도 없다고 본다. 오직 현재만 살아가는 동물들에게는 과거를 간직한 기록이나 미래에 대한 계획이 없다고 믿는다. 하지만 이건 잘못된 생각이다. 동물도 기억할 수 있고 과거로부터 배운다. 우리와 마찬가지로 감정이 있어서 사랑하고 싸우기도 한다. 동물 종이 저마다 다르듯이 동물 개체마다 서로 다른 특성도 존재한다. 행동생물학자 카르스텐 브렌징은 《생각하고 느끼는 동물들》을 통해 우리를 동물행동학이라는 실로 놀라운 세계로 안내한다.
