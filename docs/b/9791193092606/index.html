1054년 동서교회 분열을 교리 논쟁이 아니라 정치·문화·제국 질서가 얽힌 긴 갈등의 결과로 복원하는 스티븐 런시먼의 고전 역사서.

서상진 원문 ↗

동서 교회의 분열을 문명사적 비극으로 풀어낸 역사서다. 1054년 대분열과 1204년 콘스탄티노플 약탈을 중심으로, 기독교 세계의 단절이 어떻게 형성되었는지를 추적한다. 『가디언』이 극찬한 바와 같이 복잡한 역사를 서사적으로 풀어낸다.

저자는 분열의 원인을 단순한 교리 논쟁이 아닌 정치와 권력, 민족 간 경쟁에서 찾는다. 필리오케 논쟁보다 십자군과 침략, 상업 경쟁이 갈등을 심화시켰음을 분석한다. 동서 교회가 서로의 ‘영적 언어’를 이해하지 못한 데서 비롯된 단절을 짚는다.

11~12세기를 중심으로 펼쳐진 갈등의 흐름을 촘촘하게 재구성하며, 대분열이 단일 사건이 아닌 누적된 역사적 긴장의 결과였음을 설득력 있게 보여준다. 종교, 정치, 문화가 얽힌 복합적 충돌을 통해 오늘날까지 이어지는 문명적 균열을 성찰하게 하며, 교회사와 인류사의 중요한 전환점을 입체적으로 이해하도록 돕는 연구서다.
