단단한 기독교 시리즈 2권. 기도의 완전한 교과서도 아니고 탁월한 기도의 사람이 쓴 신비도 담고 있지 않다. 다만 너무나 힘든 상황에서 어떻게든 기도해 보려는 몸부림이 있는 사람, 기도를 시작해 보려는 사람에게 첫걸음이 될 안내와 용기를 불어넣어 주는 작은 징검다리다. 어려운 신학이 아니라 매우 현실적이고 구체적인 기도의 방법을 담으려고 노력했다.
