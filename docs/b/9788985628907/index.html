  4. Ⅲ. 유신체제의 성립과 인권위원회의 창설
  5. 1. 유신체제의 비인권적 성립과정과 구조 / 2. 유신체제 성립기의 인권상황 / 3. 유신체제 성립 직후
  6. NCCK의 움직임 / 4. 인권위원회의 창설과 기반 구축 / 5. 인권위원회의 변화
  7. Ⅳ. 정부의 인권탄압과 한국기독교교회협의회의 대응
  8. 1. 자기방어 활동 / 2. 인권침해 현장에서의 활동 / 3. 인권신학의 정립과 확산 / 4. 에큐메니칼 연대
  9. Ⅴ. 유신체제하 한국기독교교회협의회 인권운동의 특징
  10. 1. 민주화운동을 보호하는 인권운동 / 2. 도전과 응전의 엮임 / 3. 소수의 운동
