토마스 아퀴나스 《신학대전》 17권으로 인간적 행위를 다룬다.

강동석 원문 ↗

그리스도교 철학과 신학을 집대성한 서양 철학사의 백미이자 인간 행위를 궁극적으로 탐구한 「신학대전」 제2부 2편(제16문-제17문)을 오늘날 새롭게 소개하여 신학과 철학의 지평을 넓힌 책이다. 우리말 「신학대전」은 1985년 당시 서강대 철학과 교수였던 정의채 몬시뇰이 제1권을 번역한 이래 올해 나온 17권까지 윤종국 신부, 김춘오 신부, 김율 교수, 이상섭 교수, 김정국 신부가 번역에 참여했다. 이번에 나온 17권은 서강대 이상섭 교수가 옮겼다.
